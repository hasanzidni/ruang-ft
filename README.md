# Jadwal ruang · Fakultas Teknik UNY

Halaman publik statis (GitHub Pages) untuk aplikasi Manajemen Ruang FT UNY.

- `index.html` — jadwal penggunaan ruang
- `tv.html` — layar informasi ruang (`tv.html?kelompok=Ruang%20kuliah` untuk satu kelompok)
- `masuk.html` — masuk pengelola (khusus akun @uny.ac.id)

Data jadwal diambil langsung dari layanan Apps Script fakultas. Berkas di repositori ini DIBANGUN OTOMATIS
oleh `tools/bangun-web.js` di project utama — jangan diedit langsung di sini.
